# Bike Sales Performance Dashboard (Excel)

## Project Overview
This project analyzes transactional bike sales data and presents key business insights through an interactive Excel dashboard. The goal is to demonstrate data cleaning, exploratory analysis, and KPI reporting using Microsoft Excel.

## Business Questions
- How do bike sales perform across regions and customer segments?
- Which product categories generate the highest revenue?
- What are the key sales trends over time?

## Data Preparation
- Cleaned and standardized raw sales data
- Handled missing values, duplicates, and inconsistent categories
- Created calculated fields for KPI analysis

## Analysis & Dashboard
![Dashboard](<Bike Sale Dashboard.png>)

The Excel dashboard focuses on customer demographics and purchasing behavior:
- Age bracket distribution per purchase
- Average income per purchase
- Customer commute distance analysis

Interactive slicers are provided for:
- Region
- Marital status
- Education level

## Tools Used
- Microsoft Excel (Pivot Tables, Pivot Charts, Slicers)

## Output
The final Excel dashboard provides a clear, management-ready view of sales performance and supports data-driven decision-making.
